Where the complexity lives

Complexity here is McCabe's count: one plus every decision path (if, loop, exception, and/or) in a function. Across 74 functions only 5 pass 20, and the busiest is write_reports() in cti/disseminate.py at 41: it builds the whole intelligence report in one function. That is the first place to split if the report grows. The web handlers in app.py come next because one function routes every request.
