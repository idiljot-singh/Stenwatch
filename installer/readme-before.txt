Stenwatch 0.2 (C# edition), beta

What it does
  Narrows every published vulnerability to the few that matter in your organisation, shows the evidence behind each priority, and checks that the fixes actually happen.

What to expect on first start
  - The app opens on a Guide page. Tick "Example Organisation" on Overview to try everything with fictional data.
  - Real use needs a vulnerability database (cve.db). Choose an existing one on the Collection page, or sync the public feeds (first full sync about 15 minutes).
  - Your data lives in %APPDATA%\Stenwatch and survives updates.

Beta notes
  - Unsigned: Windows SmartScreen shows "unknown publisher". Choose More info, then Run anyway.
  - Features are labelled Validated, Proposed, Not validated and so on; see Documentation in the Start menu for what has and has not been tested.
  - Everything Stenwatch writes is marked TLP:AMBER.
